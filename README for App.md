# DBA Thesis: Readiness Scorecard Application

Interactive web application supporting the practical contribution in:

**"Exploring Acceptance and Adoption Preferences for AI-Based Software Sensors as Replacements for Hardware Sensors in Active Production Lines"**

Sudarshan Mantri, DBA, ESGCI Paris, 2026

## Two Assessment Modes

| Mode | Audience | Questions | Dimensions |
|------|----------|-----------|------------|
| Adoption Readiness | Manufacturing Plants | 21 | Technical Readiness, Workforce Readiness, Organizational Governance, Commercial Readiness |
| Market Readiness | Technology Vendors | 17 | Trust and Validation, Change Management Support, Deployment Flexibility, Pricing Transparency |

## How to Use

1. Open `Readiness-Scorecard-App.html` in any browser (no installation required)
2. Select an assessment mode
3. Rate each question on a 1-5 scale
4. View results: radar chart, dimension scores, readiness band, executive summary with recommended actions
5. Download report via browser print-to-PDF

## Readiness Bands

| Band | Score Range | Interpretation |
|------|------------|----------------|
| Not Ready | Below 2.5 | Critical gaps exist |
| Conditionally Ready | 2.5 to 3.5 | Targeted investments needed |
| Ready to Proceed | Above 3.5 | Sufficient readiness for pilot or engagement |

Thresholds are calibratable from the landing screen.
